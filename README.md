## 📖 About the Project

TradeSim Pro is a virtual stock trading simulator built for learning purposes. Users get ₹1,00,000 virtual balance to practice trading with 35+ real Indian stocks like Reliance, TCS, HDFC, Infosys, ITC, etc.

The app shows live simulated prices, portfolio tracking, profit/loss, transaction history, and stock market tutorials.

---

## ✨ Features

- Login & Signup system
- ₹1,00,000 virtual balance
- 35+ Indian stocks
- Live price simulation (updates every 3 seconds)
- Buy & Sell stocks
- Portfolio tracking with P&L
- Transaction history
- Watchlist
- Live charts (Chart.js)
- Market news
- Leaderboard
- Tutorials for beginners
- Risk warning / disclaimer
- Mobile-friendly design
